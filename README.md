# WuwaTappo全图鉴版

为 WuwaTappo 增加一个可开关的 **本地全图鉴模式**：在本地浏览全部图鉴，选择角色、配件和表情。开启时强制阻断修改版与服务器的连接，并禁止进入联机；关闭后恢复普通背包、外观及联网。

本项目是非官方修改项目，与 WuwaTappo 官方无隶属关系。**本地全图鉴不等于账号获得道具，不会把本地物品写入服务器。**

## 下载 1.0

前往 **[Releases 下载页面](https://github.com/Averionx/WuwaTappo-FullAtlas/releases/latest)**，在 Assets 中下载 `WuwaTappo全图鉴版-1.0-Setup.exe`。普通使用者无需下载源码，也无需另装 Python、Node.js 或手动复制整个文件夹。

- 系统：Windows 10 / 11，x64。
- 修改版版本：**1.0**；本次适配的官方程序版本：**1.0.1**。两者版本号独立。
- 安装包包含程序、本地素材、本地服务及专用 Microsoft WebView2 固定版本运行时。
- 当前快照：**899 项图鉴、3,098 个 PNG 素材文件**。未来数量由官方目录决定。

## 使用

1. 双击安装包，安装后从桌面 **WuwaTappo全图鉴版** 快捷方式启动。
2. 右键桌宠 → **设置** → 开启 **本地全图鉴（离线）**。
3. 在图鉴或背包中浏览、选择本地外观；仍保留角色专属适配限制和表情数量限制。
4. 要使用普通账号功能，先关闭开关。页面会重新加载一次，以恢复普通数据和网络。

默认关闭本地全图鉴。安装和启动需要管理员权限，用于添加、验证及移除只针对本修改版的 Windows 防火墙规则。不要关闭 Windows 防火墙；规则无法验证时，本地模式会拒绝开启。

## 注意事项

- **开启时无法联机。** 账号登录、开宝箱、合成、服务器奖励等线上操作均不可用；本地素材从 `127.0.0.1:43229` 读取。
- **关闭后恢复联网。** 开关只切换本地派生视图，不修改服务器库存。修改版使用独立登录目录，正常联网模式首次使用账号功能时需要自行登录。
- 不要把本地显示的全图鉴视作官方账号解锁，也不要尝试将本地状态同步到线上。
- 原版可以单独保留，本安装包不覆盖原版。卸载时会先移除本安装目录对应的防火墙规则。
- 若开关异常或关闭后仍无法连接，先使用开始菜单里的 **恢复本地版联网**。服务端维护、账号状态和官方强制升级不属于本地断网规则故障。
- 请从本仓库 Releases 下载并核对 `SHA256SUMS.txt`。发布包没有商业代码签名；遇到系统拦截时先核对来源和哈希，不要关闭系统安全防护。
- 专用 WebView2 运行时不会随系统共享版本自动升级。需要通过后续发行版更新它。

## 新增图鉴和强制更新

先关闭本地全图鉴，再到设置点击 **更新本地图鉴 → 检查并同步**。普通模式启动时也会检查素材更新。只有目录映射和全部素材下载校验通过后才切换缓存；下载失败继续保留原缓存。离线开启期间禁止联网同步，同步期间禁止开启离线模式。

**素材更新与程序升级不同。** 若官方只是新增图鉴且接口结构兼容，可以同步加入；若官方强制升级 EXE 或改变数据结构，需要重新适配。本项目不承诺自动支持未来所有官方版本，也不绕过官方账号验证或服务器版本要求。请勿直接在修改版内用官方安装程序覆盖更新，否则可能丢失本地全图鉴功能。
