## 这是什么项目？

**WuwaTappo全图鉴版**在原版 Windows 桌宠的基础上，增加可开关的本地全图鉴、后台自动点击和自动开宝箱。保留原版角色形象、配件、表情和动作，可以在背包或图鉴中搭配喜欢的外观，也可以随时关闭本地图鉴，恢复真实账号的物品与装扮。

后台助手直接沿用桌宠原有的敲击动作和计数流程。你正常打字、切换输入法或按住鼠标拖动时，自动点击会暂时避让，空闲后继续运行；自动开箱独立检查，到期后不需要等你停用键鼠。不向其他软件输入字符，不移动鼠标或切换前台窗口。自动点击和自动开箱分别控制，两个开关可以独立使用。

### 自己玩用全图鉴，联机时用账号收藏

平时一个人使用桌宠时，可以开启本地全图鉴，直接挑选喜欢的角色、配件和表情，不必等账号逐个开出来。同时，你可以开启后台自动点击和自动开箱，按原版流程累积真实点数、领取宝箱，为账号慢慢积累实际拥有的物品。

等到想和朋友联机时，关闭本地全图鉴即可恢复账号背包。**之前真实开箱获得的物品会保留，可以带到正常模式和联机中使用**，不用因为平时使用本地图鉴，就放弃积累自己的账号收藏。

| 使用场景 | 图鉴与物品 | 点击和开箱 |
| --- | --- | --- |
| 一个人陪伴、搭配外观 | 开启本地全图鉴，使用本机完整角色、配件与表情 | 可以同时累计真实点数、自动领取真实宝箱 |
| 想和朋友联机 | 关闭本地全图鉴，使用账号实际拥有的物品 | 已有点数与真实奖励保留，自动化开关也保留 |

宝箱仍按原版冷却、费用和掉落结果运行。账号收藏需要逐步获得，**本地全图鉴开关不会直接把全部物品写入线上账号**。

**修改版 1.3.4 适配官方 1.0.3。本地全图鉴只改变本机物品展示与装扮，开启时禁止进入联机房间。两种模式共用原版真实账号的累计点数、可用点数、冷却和开箱奖励。** 图片、公告、登录及更新正常联网。

这是非官方修改项目，与 WuwaTappo 官方无隶属关系。本地全图鉴不等于账号获得道具。

## 1.3.4 更新了什么？

- **适配官方 1.0.3**：保留原版快捷键自定义、全屏自动游戏模式等功能。
- **打字自动表情**：新增独立开关。先在背包装备表情，真实文字输入时随机弹出已装备的表情，持续输入间隔约 2～4 秒；后台连点、鼠标和组合快捷键不触发，停止输入后也不会定时弹出。复用手动点击的原版气泡与房间发送流程，联机接收效果仍需大家帮助测试。
- **控制台独立入口**：在左侧“联机”下方、“设置”上方集中放置控制台，更容易找到新增功能。沿用原版背景与配色，统一管理本地全图鉴、自动点击、自动开箱、打字表情、开箱记录、每日统计、房间历史和更新，概览可直接切换本地图鉴。
- **分类收集进度**：全部、角色、配件、表情分别显示真实已收集数量、总数、百分比和比例进度条；全图鉴总进度只在“全部”页显示，本地全图鉴模式隐藏。
- **本地预设修复**：本地模式下保存、应用和删除预设改为本机操作，不再误请求服务器；支持 5 套搭配和重启保留，关闭本地模式后继续使用账号预设。
- **房间历史管理**：在联机页和控制台查看成功进入过的房间，支持收藏置顶、再次加入和删除单条本机记录；房间信息刷新不会把已删除记录加回来。
- **版本检查与一键更新**：分开显示官方最新版、GitHub 修改版最新版、当前安装版本及基底。检测到官方新版但没有对应适配包时提示等待；修改版可用时提示更新，版本一致时明确显示无需更新。更新可选，保留下载校验、备份、原地替换、重启与启动失败回退。
- **任务栏图标默认隐藏**：桌宠默认不再占用底部任务栏，保留右下角托盘入口；需要任务栏入口或 OBS 采集时，仍可在原版设置中打开“显示任务栏图标”。
- **升级清理修复**：修复子进程占用升级器临时运行库，导致退出时提示无法删除临时目录的问题。
- **控制台入口与布局修复**：修复入口未出现的问题，整体内容上移，滚动条改为原版细窄暖色样式。
- **单 EXE 绿色版**：直接双击使用，首次自动准备本地程序和素材；与安装包、原地升级包一同提供。功能和界面与安装版一致，只是免去安装步骤。

| 共用真实账号点数与奖励 | 两种图鉴模式共用累计点数、可用点数、宝箱冷却与真实奖励；切回正常模式后，真实开出的物品继续保留。 |

| 分类收集进度 | 正常账号模式下显示全图鉴、全角色、全配件或全表情的真实进度，按唯一物品计数，重复物品不重复累计；新物品到手后自动刷新。 |
| 公开图鉴与图片同步 | 检查并同步官方公开目录、物品映射与图片，校验完成后切换缓存，失败保留旧缓存；本地全图鉴开启时也能同步。 |

| 自动开宝箱 | 与自动点击独立开关。账号已登录、余额达到阈值、冷却结束且原版按钮出现后约 2 秒领取；使用键盘或鼠标不会重置等待，仍遵守原版费用和服务器结果。 |

### 版本检查会显示什么？

| 检测结果 | 页面提示与操作 |
| --- | --- |
| 官方发布新版 | 显示具体最新版本和当前官方基底，标记“有新版” |

## 下载与升级

前往 [GitHub Releases 发行与下载页面](https://github.com/Averionx/WuwaTappo-FullAtlas/releases)，在对应版本的 **Assets** 中选择安装包。本文对应 **1.3.4（官方基底 1.0.3）**，旧版附件不包含 1.3.4 的新功能。功能与实测说明见 [开发记录](docs/DESKTOP_PROGRESS.md)。

- 系统：Windows 10 / 11，x64。
- **免安装绿色版**：下载 **WuwaTappo-FullAtlas-1.3.4-Portable.exe**，放到准备长期使用的目录后双击即可；只需下载这一个 EXE，无需安装向导。
- 已安装全图鉴版：退出桌宠，运行 **WuwaTappo-FullAtlas-1.3.4-Upgrade.exe**。直接升级原目录，无需重新安装官方程序。
- 新安装：使用 **WuwaTappo-FullAtlas-1.3.4-Setup.exe**。包含本地素材、服务和专用 WebView2 运行时，不需要另装 Python 或 Node.js。GitHub 附件使用英文文件名，安装界面和快捷方式名称仍为 **WuwaTappo全图鉴版**。
- 升级保留账号目录、本地选择、统计、收藏和已同步的素材。安装与启动可能需要 Windows 管理员确认；旧版整段断网规则会自动移除。
- 下载后核对随包的 SHA256 清单。程序和安装包没有商业代码签名。

### 绿色版怎么用？

1. 把绿色版 EXE 放到空间充足、准备长期使用的文件夹，双击运行；Windows 若要求管理员确认，请本人确认。
2. 首次启动会把程序、图片和专用运行时解压到 EXE 旁的 **`WuwaTappoPortableData`**，需要一些准备时间。此后仍双击同一个 EXE 启动。
3. 账号登录、预设、统计、本地图鉴设置和已同步素材保存在这个数据目录中。绿色版与安装版的配置分别保存，不会自动导入另一份的账号。
4. 要连数据一起搬到其他位置，请先退出桌宠，再把 **EXE 和同名数据目录一起移动**；只发送 EXE 给别人即可重新初始化，**不要把个人数据目录发给别人**。
5. 安装版和绿色版不能同时运行，切换前先退出另一份。绿色版没有安装向导，也不会由启动器创建桌面快捷方式或卸载项。
6. 绿色版也能使用程序内“一键升级”。升级更新数据目录里的程序，再次打开旧的绿色启动器不会覆盖较新的程序。

单文件指下载和分发时只有一个 EXE；运行时仍需解压素材与 WebView2 文件，不是在内存中凭空运行。绿色版和安装版都包含完整资源，首次使用请预留约 3 GB 空间；功能运行仍按上文说明联网。

## 使用

1. 安装版从桌面 **WuwaTappo全图鉴版** 快捷方式启动；绿色版直接双击下载的 EXE。
2. 打开原版功能面板，点击左侧 **控制台**（位于“联机”下方、“设置”上方）。
3. 在 **控制台 → 功能设置** 中开关本地全图鉴，配置自动点击、自动开箱和打字自动表情。
4. 在背包或图鉴中搭配角色、配件和表情；本地模式点击“我的预设”的加号即可保存本机搭配。
5. 需要打字自动表情时先装备表情，再开启对应开关。真实文字输入连续 2 次后可触发，持续输入间隔约 2～4 秒；停止输入后不定时弹出。
6. 需要联机时关闭本地全图鉴，使用账号实际拥有的物品；联机页下方可查看历史房间。
7. 在 **控制台 → 更新** 检查官方及修改版，或点击原版设置底部“检查更新”。项目与反馈入口位于设置页和控制台底部。

## 本地模式与联网

本地全图鉴只是本机的展示和选择层。公告、登录、素材下载、公开图鉴同步和修改版更新继续联网；不会新增针对整个程序的断网防火墙规则。

联机房间的创建、加入和连接会被阻止。未拥有的本地图鉴物品不会通过合成、账号外观和预设写入真实账号。**真实开箱接口保持可用**，自动开箱在两种模式下都要求原版账号登录，沿用原版按钮、费用、冷却及服务器结果。断网、登录失效或余额不足时不能获得服务器奖励。

1.1 的旧模拟点数和本地开箱不会转换为服务器奖励。升级后作为历史存档保留，新的点击全部使用原版真实计数流程。图鉴全解锁与账号实际拥有的物品不同，关闭本地开关后以账号背包为准。

## 新增图鉴与一键更新

控制台功能设置中的 **本地图鉴资源 → 检查并同步图鉴** 在本地全图鉴开启时也可使用。普通启动也会检查公开素材。目录、ID 映射和全部图片校验完成后才切换缓存，失败保留原缓存；其他窗口会同步刷新新目录。当前快照为 899 项图鉴、3098 个 PNG，数量随官方公开目录变化。

修改版启动后以及每 30 分钟检查官方版本和 **Averionx/WuwaTappo-FullAtlas** 的正式 Release。更新是可选的，不再强制锁定桌宠。检测到官方新版后，会核对 GitHub 发行说明中的适配基底；没有可确认的对应适配版时，显示“等待作者适配”，不会直接下载官方安装器覆盖修改版。

有完整升级 ZIP 与有效 SHA256 清单的对应版本时，可点击“一键升级”。程序自动下载、校验、备份、替换并重启，新前端启动确认成功后清理旧备份，启动超时回退。下载失败或校验失败保留旧程序。可以稍后更新；网络故障、普通代码提交、README 修改、草稿和预发布不会锁定程序。旧的强制更新记录也不会继续生效。

素材更新与程序适配不同。官方新增素材且结构兼容时可同步；官方改变 EXE 或接口结构时，需要验证新的适配版。不会盲目运行官方安装器覆盖修改版，也不承诺支持所有未知版本。首次升级仍建议自行保留目录副本，断电和磁盘损坏不属于正常回退可以保证的情况。

## 常见问题

**不开自动点击，只开自动开宝箱可以吗？**

可以。正常打字或点击桌宠仍会累计点数。只开启自动开箱时，账号已登录、冷却结束且余额达到阈值后，助手会等待原版开启按钮出现约 2 秒再领取。

**宝箱到期时，我还在打字或使用鼠标，会影响自动开箱吗？**

不会因为键鼠正在使用而等待。键鼠避让只暂停后台自动点击；自动开箱通过桌宠内部的原版按钮领取，仍检查登录、余额、冷却和按钮状态，不需要你停下手里的操作。

**本地全图鉴开启时，可以自动点击和开箱吗？切回正常模式会保留吗？**

可以。新点击沿用真实计数，开箱使用真实账号的余额和服务器结果，切回正常模式后保留真实获得的物品。开箱需要保持登录和联网。本地图鉴额外显示的未拥有物品只是本机展示，不能作为账号物品使用。

**切换控制台页面或关闭原版面板，会停止挂机吗？**

不会。控制台嵌在原版面板中，切换页面或关闭面板只停止界面刷新。点击“暂停点击”只暂停自动点击，自动开箱开关保持原样；需要全部暂停时，点击“停止全部自动任务”。退出桌宠程序才会结束这次后台运行。

**为什么本地图鉴开启后不能进入联机？**

本地图鉴可以显示账号尚未拥有的外观，开启时会禁止创建、加入和连接联机房间。需要联机时关闭本地全图鉴，恢复账号物品与装扮即可；公告、登录、素材下载、真实开箱和更新仍然正常联网。

**本地模式的预设会上传账号吗？**

不会。本地模式的预设保存在本机配置中，独立于服务器账号预设。可以新增、应用、删除和重启后继续使用；关闭本地全图鉴后显示原来的账号预设。

**联机自动表情测试说明**

作者没朋友测试联机模式，麻烦大家帮忙测试一下，遇到问题请到 [GitHub Issues](https://github.com/Averionx/WuwaTappo-FullAtlas/issues) 反馈。

本机打字自动表情已由用户实测确认；联机发送复用原版手动表情流程，但尚未完成双客户端可见性实测。请在正常账号模式、已关闭本地全图鉴的情况下测试，并说明双方版本及复现步骤。
