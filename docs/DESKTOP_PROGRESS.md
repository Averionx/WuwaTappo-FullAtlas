# 桌面版开发与验证

## 1.2 当前实现

官方基底继续为经过 SHA256 验证的 1.0.2。1.2 取消独立模拟点数与模拟开箱，本地全图鉴只负责本机物品展示和装扮，联机房间仍被禁止。

- 原版累计/余额 getter、increment/addLocalClickCount、原生保存及退出登录计数恢复原逻辑。两种模式共用账号计数，不导入 1.1 的模拟点数。
- 两种模式均点击原版真实开箱按钮，保留登录、余额、冷却、扣费与真实服务端响应。移除模拟奖励随机抽取和模拟开箱接口。
- 修复键鼠持续操作会反复清空开箱等待计时的问题：键鼠空闲检查只用于自动点击，自动开箱独立检查原按钮，不等待用户停止打字、移动或拖拽鼠标。状态栏分别显示点击避让和开箱值守。
- 在原版开箱成功分支记录奖励名称、稀有度、费用、时间、宝箱位置与来源。事件 ID 去重，失败重试仅补记日志，不重开宝箱。
- renderer-start、关闭控制台和切换图鉴不再重置开关或会话；不再销毁/卸载原版面板，不再因关闭本地图鉴重载主桌宠。
- 新控制台使用卡片布局，分为概览、开箱记录、每日统计、房间历史及设置与更新。浏览器 UI 预览使用明确标记的演示数据，不能视为真实账号领奖证据。
- 启动及每 30 分钟监控 Averionx/WuwaTappo-FullAtlas 正式 Release。只有有效新版升级包与校验清单齐全才触发必须更新。确认后持久保存更新要求，下载失败可重试；版本不匹配的前端不能通过升级健康检查。

当前代码检查：30 个 Python 测试通过；控制器 38 项检查通过；4 个实际生成模块解析及导入验证通过。隔离执行实际生成的原版计数、保存、退出登录、按键处理和开箱函数，确认两种模式均使用相同的计数与服务器开箱分支。渲染器检查还覆盖奖励日志保存失败时继续运行、后续只补存记录。新增持续键鼠输入回归：两种图鉴模式、自动点击开关分别开/关时均可领取两个就绪宝箱，2 秒等待与原按钮状态限制保留，自动点击仍暂停；登录、余额、强制锁定、不可用或隐藏的按钮仍阻止开箱。浏览器已验证设置保存、切页、七天统计及关闭入口。

1.2 已在现有目录原地升级，匹配版本的新前端健康确认成功。实机正常 → 本地图鉴 → 正常连续测试，后台设置保持开启；三个观察段自动发送/原计数器确认分别为 14/14、7/7、5/5。切换不出现模拟余额，不重载主桌宠。

本地图鉴开启时实际通过原版按钮自动领取一份服务器奖励，原版扣费 1000 点；切回正常模式后，累计点数及余额满足“原余额 + 真实累计增量 − 1000”，奖励日志保留，原账号背包可见所得配件。未把旧模拟数据合并到账号。实机资料只存本机构建目录，不作为发行附件。

真实房间重进、双显示器恢复及升级中途断电尚未完成实测。强制更新以隔离的正式/预发布/附件缺失/校验错误/断网及缓存状态测试验证，不通过发布虚假高版本影响其他用户。

参考项目仅用于研究功能和展示方式：WuwaTappo-helper（仓库未发现独立许可文件，不复制源码）、AutoTappo（MIT）、WuwaTappoPlus（GPL-3.0-only）。1.2 控制器与界面为本项目自行编写，没有导入这些项目的模块。
