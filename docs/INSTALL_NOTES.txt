WuwaTappo全图鉴版 1.2（官方基底 1.0.2）

退出旧桌宠后运行原地升级工具，无需重装官方版本；新安装使用完整 Setup。
本地全图鉴只改变物品展示和本机装扮，并禁止联机房间。其他网络正常。
两种图鉴模式使用同一个原版真实账号点数、余额、宝箱冷却和服务器奖励。
开箱要求账号登录且网络可用。旧版模拟点数只做历史存档，不能转成账号奖励。
设置 → 挂机与统计 → 打开控制台，可管理自动点击、开箱、奖励记录和统计。
关闭控制台不会停后台；停止全部自动任务会同时关闭自动点击与自动开箱。
打字、切换输入法或按住鼠标时仅暂停自动点击；自动开箱不等待键鼠空闲。
开箱仍通过桌宠内部原版按钮执行，不注入 Windows 键鼠、不抢焦点。
程序启动及每 30 分钟检查本项目正式 Release；完整有效新版发布后必须更新。
下载失败不替换程序，可重试或退出；升级校验失败不会绕过检查。
程序仍依赖原版 WebView2，不能保证几兆内存或绝对零 CPU。
