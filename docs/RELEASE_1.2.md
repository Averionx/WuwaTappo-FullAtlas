# WuwaTappo全图鉴版 1.2

适配官方桌宠 **1.0.2**。自己玩时自由使用本地全图鉴，同时通过真实点击和开箱积累账号物品；联机时关闭本地全图鉴，使用账号已经获得的收藏。

## 下载

- **新安装**：`WuwaTappo-FullAtlas-1.2-Setup.exe`，内含桌宠、本地素材、服务与专用 WebView2。
- **已有全图鉴版升级**：`WuwaTappo-FullAtlas-1.2-Upgrade.exe`，退出旧桌宠后运行，保留原目录、账号、设置和素材，无需重装官方版本。
- `WuwaTappo-FullAtlas-1.2-x64-update.zip` 为程序内更新使用的包，不含素材缓存和运行时，不作为新安装的替代品。
- 下载后核对 `SHA256SUMS.txt`。附件使用英文文件名，安装界面和快捷方式仍显示“WuwaTappo全图鉴版”。

## 更新内容

- 本地全图鉴只负责物品展示和本机装扮；两种图鉴模式共用真实账号的累计点数、可用点数、宝箱冷却与服务器奖励。
- 本地全图鉴开启时禁止进入联机房间，公告、登录、图片下载、真实开箱和更新继续联网。
- 新控制台展示账号点数、发送与领取次数、宝箱1和宝箱2的进度；支持 1、5、10 次/秒，关闭面板继续运行。
- 自动点击和自动开箱独立开关。打字、Shift 或鼠标操作只暂停自动点击，自动开箱满足原版条件后照常领取，不等待键鼠空闲。
- 开箱记录保存真实成功返回的物品、时间、稀有度、来源和消耗。记录保存失败只补存日志，不重复开宝箱。
- 每日点击统计、显示器记忆、房间历史与收藏，图鉴新增资源同步。
- 启动及每 30 分钟检查本项目正式 Release，完整有效新版发布后必须更新，支持校验、备份、原地替换、重启与启动失败回退。
- README 补充原版 Logo、透明圆角的真实截图、使用方法与安卓版入口。

## 使用与注意事项

Windows 10/11 x64。右键桌宠 → 设置 → 本地全图鉴；后台功能在“挂机与统计”中配置。需要联机时关闭本地全图鉴。

真实开箱需要保持账号登录、联网、余额足够且原版冷却结束。新账号物品按原版掉落逐步获得，本地图鉴不会直接把全部物品写入线上账号。1.1 的模拟点数只做历史存档，不转换成服务器奖励。

30 个 Python 测试、38 项控制器检查、实际生成的原版函数执行检查以及持续输入开箱回归均通过；已实测原地升级、两种模式共享计数及真实账号领奖。真实房间重进、双显示器恢复和断电回退仍未完成实机验证。
