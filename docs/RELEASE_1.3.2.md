# WuwaTappo全图鉴版 1.3.2

适配官方 **1.0.3**。

- 左侧“设置”下新增“控制台”，沿用原版背景和暖色配色；新增功能集中到原页面中，不另开窗口。
- 修复本地模式添加预设误调用服务器而提示网络繁忙的问题。本机独立保存 5 套搭配，支持应用、删除、重启保留；账号预设不变。
- 线上图鉴分类栏下新增全图鉴收集进度：真实“已收集 / 总数”、百分比和比例填充条。跟随原版图鉴及背包更新，本地模式隐藏，不重复累计同一物品。
- 联机页加入区域下方新增房间历史、房主、进入时间，支持收藏置顶和再次加入；仅记录成功进入的房间。
- 打字自动表情读取已装备槽位。修复现代输入框识别，连续 2 次文字键后可触发，持续输入间隔 2～4 秒；后台连点不触发，停止输入不定时弹出。本机已由用户确认正常弹出。
- 原设置中的“检查更新”现在会进入控制台并执行检查。取消强制更新，旧强制记录不再锁定桌宠。先核对官方新版及 GitHub 对应适配基底，无对应适配包时等待作者更新。
- 设置和控制台底部提供本项目 GitHub 与反馈入口。

作者没朋友测试联机模式，麻烦大家帮忙测试一下，遇到问题请到 [Issues](https://github.com/Averionx/WuwaTappo-FullAtlas/issues) 反馈。双客户端表情可见性与真实房间重进尚未实测；代码中的联机协议检查不能替代真实接收端测试。

新安装选择 `WuwaTappo-FullAtlas-1.3.2-Setup.exe`；已有版本退出桌宠后使用 `WuwaTappo-FullAtlas-1.3.2-Upgrade.exe`。`WuwaTappo-FullAtlas-1.3.2-x64-update.zip` 用于程序内升级。保留账号、素材、本机搭配、预设和设置。
