# WuwaTappo全图鉴版 1.3.3

适配官方 **1.0.3**。

- 修复左侧“控制台”入口未出现的问题，现在位于“设置”下方。沿用原版背景，整体内容向上调整，增加可用空间。
- 控制台概览新增本地全图鉴快捷开关。切换图鉴不会重置自动点击、自动开箱或打字自动表情设置；账号点数与真实奖励仍共用。
- 控制台和联机页的房间历史均可删除单条记录。删除只清理本机历史，不会退出或删除服务器房间；房间信息刷新不会把刚删除的记录加回来，重新进入时才再次记录。
- 控制台和房间历史使用原版细窄暖色滚动条。
- 更新页依次展示“官方最新版”“修改版最新版（GitHub 已发布）”“当前安装版本及官方基底”。本机测试版本高于 GitHub 版本时明确提示无需降级。
- 修复升级后子进程继承临时运行库目录、导致退出时提示临时目录无法删除的问题；启动时改用安装目录中的运行库。
- 保留本地预设、线上真实图鉴收集进度、打字自动表情及可选一键更新。官方新版尚无对应适配包时等待作者更新，不强制锁定桌宠。

作者没朋友测试联机模式，麻烦大家帮忙测试一下，遇到问题请到 [Issues](https://github.com/Averionx/WuwaTappo-FullAtlas/issues) 反馈。双客户端表情可见性与真实房间重进尚未实测。

新安装使用 `WuwaTappo-FullAtlas-1.3.3-Setup.exe`；已有版本先退出桌宠，再运行 `WuwaTappo-FullAtlas-1.3.3-Upgrade.exe`。`WuwaTappo-FullAtlas-1.3.3-x64-update.zip` 用于程序内更新。升级保留账号、素材、本机搭配、预设和设置。
