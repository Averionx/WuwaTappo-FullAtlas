# WuwaTappo全图鉴版 1.3.4

适配官方 **1.0.3**。

- 打字自动表情提供独立开关。真实文字输入时随机弹出已装备的表情，持续输入间隔约 2～4 秒；沿用原版手动气泡和房间发送流程。
- 控制台独立入口位于“联机”下方、“设置”上方，更容易找到新增功能。沿用原版背景，集中管理图鉴、点击、开箱、表情、统计、历史和更新。
- 图鉴各分类分别显示全角色、全配件、全表情收集进度；全图鉴总进度仅在“全部”页显示，进度跟随真实账号数据变化。
- 修复本地预设误请求服务器的问题，支持本机保存、应用、删除和重启保留；房间历史支持收藏、再次加入和删除本机记录。
- 更新页区分官方最新版、GitHub 最新修改版和当前安装版本；没有对应适配包时提示等待，版本一致时显示无需更新，有完整可用包时提示可更新。
- 默认隐藏底部任务栏图标，保留托盘。升级时只迁移一次旧配置，之后仍可在原版设置中重新打开“显示任务栏图标”。
- 退出桌宠后保存并释放本目录后台服务；绿色版短暂等待已退出实例释放端口，解决切换版本时后台残留的冲突。
- 控制台入口与布局修复：修复入口缺失，整体内容上移，并使用原版细窄暖色滚动条。
- 单 EXE 绿色版：功能和界面与安装版相同，只免去安装步骤。下载一个 EXE 即可启动，首次自动准备旁边的数据目录。

现有功能完整清单与使用方法见 [README](../README.md#完整功能)。

作者没朋友测试联机模式，麻烦大家帮忙测试一下，遇到问题请到 [Issues](https://github.com/Averionx/WuwaTappo-FullAtlas/issues) 反馈。双客户端表情可见性尚未实测。

新安装使用 `WuwaTappo-FullAtlas-1.3.4-Setup.exe`；已有版本先退出桌宠，再运行 `WuwaTappo-FullAtlas-1.3.4-Upgrade.exe`；免安装使用 `WuwaTappo-FullAtlas-1.3.4-Portable.exe`。另提供程序内更新 ZIP，升级保留账号、素材、预设和设置。
