# WuwaTappo全图鉴版 1.3.5

适配官方 **1.0.3**，保留 1.3.4 及之前的功能。

- 修复开机自启动直接启动本体、未先启动本地服务而出现“Failed to fetch”的问题，自动迁移当前目录的旧任务。
- 启动及每 30 分钟检查 GitHub 正式发行版，确认有完整适配的升级包与校验清单后要求更新；没有对应适配包时等待作者更新。
- 独立固定位置的置顶更新窗口，仅提供立即更新和退出；下载失败可重试。沿用校验、备份、原地替换、重启和启动失败回退。
- 预览明确标注，不下载程序。系统安全窗口和其他同样置顶的窗口仍可能覆盖，不能承诺绝对不可覆盖。

实机已验证原地升级、手动触发真实登录任务启动、账号与设置和奖励记录保留、独立更新窗口及完整退出流程。Windows 重启后的登录触发、双客户端联机表情可见性等仍有待更多实机反馈。

作者没朋友测试联机模式，麻烦大家帮忙测试一下，遇到问题请到 [Issues](https://github.com/Averionx/WuwaTappo-FullAtlas/issues) 反馈。
