# WuwaTappo全图鉴版 1.3.6

适配官方 **1.0.3**，保留 1.3.4、1.3.5 及之前的功能。

- 更新流程改为独立后台任务，重复点击不会创建多个下载任务；跨进程独占安装、等待旧文件释放，自动备份、替换、重启及确认启动。更新时重新打开启动器不会抢先启动旧 EXE。
- 下载显示实际字节数、总大小与进度条；校验、解压、备份替换和重启显示阶段状态。旧桌宠退出后，同款暖色圆角进度窗口接续显示，沿用原版字体并去掉系统标题栏，底部按钮保持可见，完成后自动关闭。
- 更新弹窗显示对应版本的真实更新详情，长内容使用控制台同款暖色细滚动条，底部操作按钮固定可见。
- 修复失去焦点后置顶被取消；Windows 安全提示和其他置顶窗口仍可能覆盖。
- 修复 GitHub 匿名 API 限流后公开页面回退缺少适配信息的问题；读取失败明确报错，已确认的更新要求保留。
- 移除控制台的预览更新弹窗按钮及预览接口。
- 桌宠右键菜单在设置上方增加控制台入口。菜单独立处理，点击外部或按 Esc 可收起，关闭并释放拖拽状态后再打开页面，修复菜单卡住和控制台打不开的问题。
- 独立原地升级包支持桌宠运行中或已关闭时使用：运行时先请求保存退出，再等待文件释放并替换；无法退出时保留旧程序，避免重复启动。

1.3.5 的更新器仍是旧代码；如果旧版更新失败，可运行本版 Upgrade.exe 原地升级，无需重新安装官方版。

双客户端联机自动表情可见性仍待用户帮助测试与反馈。
