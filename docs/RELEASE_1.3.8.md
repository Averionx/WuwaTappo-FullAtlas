# WuwaTappo全图鉴版 1.3.8

适配官方 **1.0.4**。

- **包体压缩优化**。后台打包排除未启用的 NumPy 数组依赖，安装包提高 LZMA2 压缩级别，绿色版和程序内更新 ZIP 使用 LZMA 压缩。
- **完整素材与运行环境**。包含全图鉴素材和独立 WebView2 运行时，首次启动按原有流程准备本机数据。
- **首次解包说明**。更高压缩率会增加解包计算量，首次启动、安装及更新的耗时取决于电脑性能。程序内更新 ZIP 由桌宠更新器读取，手动升级使用 Upgrade.exe。
