# WuwaTappo全图鉴版 1.3

适配官方 1.0.3，保留快捷键自定义、全屏自动游戏模式及既有图鉴、账号点数、开箱与更新功能。

新增“打字自动表情”独立开关。先在背包装备表情，再到“挂机与统计 → 设置与更新”开启。真实文字按键且前台存在文本光标/编辑控件时，偶尔随机弹出已装备表情；持续输入间隔约 2～4 秒，停止输入后无定时弹出。自动 F24 点击、鼠标、修饰键及组合快捷键不触发。

动画与联机发送调用原版手动选择函数。账号模式进入房间时发送账号已经装备的表情 ID；本地全图鉴依然不能联机，本地选中的表情不会发往房间。无法识别文本光标的自定义编辑器会保守跳过。

输入判断不读取文本、剪贴板或按键内容日志。设置保存在本机，升级保留账号、素材缓存和已有配置。

验证记录见 DESKTOP_PROGRESS.md。代码级联机消息验证不等同于双账号实机可见性测试，后者完成前不能宣称已实测。
