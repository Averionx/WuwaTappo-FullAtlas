# 1.2 工作记录

用户最新要求覆盖 1.1 的实现选择：本地模式只改变图鉴和外观展示，不改变累计点数、可用点数、原版冷却和真实服务器开箱。两种模式共用真实计数与奖励；本地模式仍禁止联机房间，其他网络正常。

实现要求（具体完成与验证状态见 DESKTOP_PROGRESS.md）：

- 移除共享 store 的本地累计/余额 getter 覆盖、increment/addLocalClickCount 重定向、native 保存及退出登录计数替换。
- 移除模拟开箱分支与本地冷却 computed 覆盖，允许真实 chests/open 接口；原版真实按钮仍是自动开箱入口。
- 旧本地模拟计数和奖励保留为历史，不补写进账号；新奖励记录只记服务器已确认成功的结果，支持重试去重。
- renderer-start 与关闭面板不再重置后台开关、会话或设置。本地开关关闭不再 reload 主渲染器。移除新增的 destroy/unmount 干预，先恢复原版面板关闭生命周期，后台引擎留在主桌宠。
- 重做控制台：暖灰/奶油背景、白色统计卡、运行状态、开始/暂停/停止、真实余额与累计、左右宝箱进度、速度卡、真实奖励记录、七天统计、房间与设置；关闭仅关闭面板。
- 自动开箱无论图鉴开关均要求原版账号已登录，沿用原冷却和扣费；不伪造成功，不猜奖励。
- 版本改为 1.2（官方基底继续 1.0.2）。增加前端版本健康确认，避免旧代码确认新包。

新增要求：监控 Averionx/WuwaTappo-FullAtlas 正式 Release，有高于当前版本且完整有效的升级 ZIP 和 SHA256 清单时必须升级。草稿、预发布、代码提交不触发；检测失败不新建锁，已确认的更新锁跨重启保留。

构建环境和已验证的官方基底见 docs/BUILD.md。Windows PowerShell 5 脚本使用 UTF-8 BOM。先完成构建与检查，再运行升级；本机私有升级脚本、测试状态和控制令牌不进入仓库或发行包。
